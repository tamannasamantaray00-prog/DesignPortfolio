Context

The product was a white-label fintech platform for corporate and retail banking clients in different regions. Every client needed the same core experience, adapted to their market.

The problem

Build a scalable design system from scratch for this platform. It had to line up design and development, adapt to regional needs, hold up under high-volume, high-stakes workflows, and support launching more than one product.

The system at scale

What started as a foundation became a full ecosystem used across the whole platform.

My process

  1. Audited what existed. I reviewed every UI element, from buttons and colors to cards and dropdowns, and listed the duplicates and inconsistencies.
  2. Set principles. Accessibility, consistency and flexibility became the compass for every later decision.
  3. Built the visual style guide. Type scales, color tokens, iconography and spacing rules, documented once.
  4. Created a reusable component library. Buttons, forms, navigation and modals, each with usage guidance and edge cases.
  5. Wrote everything down. The what, why and how behind each component, so designers and developers could self-serve.
  6. Added version control. I tracked changes with Git and token management so updates would not break things.
  7. Brought people along. I ran demos, onboarded teams and answered questions to show how the system made work faster and more consistent.

What went wrong, and what I learned

Building a system from scratch takes real time, and it needs dedicated people to keep it alive. Being honest about where I got things wrong made the next version better.

  • I did not set up version control early. Tracking changes became difficult, designers started detaching instances, and rolling out updates got chaotic.
  • There was no proper documentation at the start, which made onboarding new designers, working across teams and handing off to developers messy.
  • Too much rigidity risked killing creativity, so the system had to leave room for judgment.

The lesson: put the structure in place before scale arrives, not after.
